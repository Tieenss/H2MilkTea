Lọc chuyên đề:
1. Client Tier (Trình duyệt Người dùng - CSR)
💻 Thu Ngân POS UI Client Comp
src/app/(dashboard)/pos/page.tsx
Giao diện bán hàng trực tiếp, chọn bàn, chọn món, nhận thông báo realtime đơn QR từ khách, kết nối máy in và tạo đơn tại quầy.
🔄 useSharedCartDraft Hook React Hook
src/app/(dashboard)/pos/hooks/useSharedCartDraft.ts
Quản lý đồng bộ giỏ hàng dùng chung giữa nhiều tablet. Xử lý WebSocket Realtime, Fallback Polling (3.5s) và OCC resolution.
🎙️ POS Assistant (Trợ lý AI) Client Comp
src/app/(dashboard)/pos/components/POSAssistant.tsx
Nhận lệnh thoại qua Web Speech API (vi-VN), auto-submit, hiển thị khung duyệt món Human-in-the-Loop trước khi nạp vào giỏ.
📱 Khách Quét QR Bàn Client Comp
src/app/order/page.tsx
Giao diện khách tự order tại bàn trên điện thoại di động. Không cần đăng nhập, bảo vệ bằng mã hóa QR Token và Idempotency Key.
🍳 Màn Hình Bếp (KDS) Client Comp
src/app/kitchen/page.tsx
Hiển thị danh sách vé chế biến theo thời gian thực (queued -> making -> completed), âm báo khi có đơn mới từ thu ngân hoặc khách QR.
2. Edge Gateway & Middleware Tier
🛡️ Next.js Edge Middleware Edge Runtime
src/middleware.ts
Kiểm soát truy cập toàn bộ route nội bộ, cấp Correlation ID (x-correlation-id) phục vụ truy vết lỗi, bảo vệ trang bằng JWT/Cookie.
⚡ Supabase Realtime Gateway WebSocket PubSub
Kênh: pos_cart_drafts & pos_orders
Kênh WebSocket phát tín hiệu tức thời khi thu ngân sửa giỏ, khách gửi đơn hoặc trạng thái bàn thay đổi.
3. Serverless API Route Handlers Tier (Node.js Server)
🛒 Cart Draft API API Route
src/app/api/pos/cart-draft/route.ts
Thực thi Optimistic Concurrency Control (OCC) với phiên bản số nguyên `version`. Trả về HTTP 409 Conflict khi phát hiện sửa đè.
📝 Orders Processing API API Route
src/app/api/orders/route.ts
Tiếp nhận đơn hàng, chống gửi trùng bằng Idempotency Key (UUID), xác thực giá phía server (Server-side Price Validation) qua DMHH.
🤖 AI Chat Endpoint API Route
src/app/api/ai/chat/route.ts
Xác thực nhân viên, tải cấu hình cài đặt AI (bật/tắt, alias, FAQ tùy biến), tải DMHH & DSBAN kích hoạt và đẩy vào Pipeline xử lý.
🔐 Server Auth & RBAC Resolver Server Utility
src/lib/supabase/server.ts
Quản lý Service Role Key bí mật, đọc phiên đăng nhập staff, tra cứu vai trò Admin / Nhân viên từ bảng DSNV.
4. AI Intelligence & Pipeline Engine
⚙️ AI Pipeline 3 Lớp Core Engine
src/lib/ai/pipeline.ts
Điều phối 3 lớp: Rate Limiting (20 req/phút) -> Rule Engine / Security Guardrails -> LLM NLU (Gemini) -> Schema Validation & Audit.
🎯 Catalog NFD & Token Scorer NLU Utility
src/lib/ai/catalog.ts
Chuẩn hóa tiếng Việt bỏ dấu (NFD), thay thế từ viết tắt (ts -> trà sữa), tính điểm F1-Score (Precision & Recall) để bắt đúng món.
🧠 Google Gemini 2.5 Flash Cloud LLM
External API / Google AI Studio
Đọc hiểu ngôn ngữ tự nhiên phức tạp, ép khuôn đầu ra dạng JSON có cấu trúc (Strict Structured JSON Schema) không sinh văn bản thừa.
5. Persistence & Supabase Database Tier (PostgreSQL)
📦 pos_orders Table PostgreSQL
Supabase Schema: pos_orders
Lưu toàn bộ đơn hàng, cột `idempotency_key` unique chống duplicate, `tracking_token` cho khách tra cứu, trạng thái đơn và bếp.
📑 pos_cart_drafts Table PostgreSQL
Supabase Schema: pos_cart_drafts
Lưu giỏ hàng nháp theo từng bàn (`table_id` primary key), cột `version` kiểu integer phục vụ cơ chế khóa lạc quan (OCC).
🗄️ DMHH, DSBAN, DSNV Tables Master Data
Bảng: DMHH | DSBAN | DSNV
Bảng giá gốc (DMHH), sơ đồ phòng bàn (DSBAN), danh sách nhân viên và cột `Phân quyền` Admin/Nhân viên (DSNV).
📜 ai_audit_logs Table Audit & Trace
Supabase Schema: ai_audit_logs
Ghi nhật ký mọi khẩu lệnh AI: câu thoại gốc, thời gian phản hồi (latency), kết quả phân tích, trạng thái xác nhận (previewed/confirmed/rejected).
